# Live-mode safety contract

**Public build status: LIVE DISABLED.**

This file exists as a stable, hashable safety artefact used by the host's live-lock tests. It is intentionally not an operational deployment runbook.

A future live-capable build must require an explicit, separately reviewed promotion decision and must preserve the architecture's core invariants: validated strategy artefacts, deterministic risk admission, trustworthy external-state reconciliation, working safety controls and explicit operator authorisation.

The public repository does not contain broker-account details, authentication procedures, deployment topology, personal capital limits or emergency operating instructions.

Changing this file changes its SHA-256 and therefore invalidates any previously recorded checklist approval by design.
